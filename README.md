# CHARLES BANKING SYSTEM

**Language:** C  
**Repository:** C-Basics-week1

## Summary
CHARLES BANKING SYSTEM is a console-based banking application written in C.  
It demonstrates conditionals, loops, functions, switch-case menus, file handling, secure password hashing (libsodium / Argon2id), transaction logging with timestamps, and colored terminal output.

## Features
- Register new account with name, numeric account number, password (or default 10Mate01), and initial deposit
- Secure login using Argon2id (libsodium)
- Deposit, Withdraw, Transfer with validation and logging
- Change password (securely hashed)
- Display account details (name, account number, balance)
- Transaction history in CHARLES_TRANSACTIONS.log with timestamps
